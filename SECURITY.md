# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Contribution Farm, please report it privately. Do not report security vulnerabilities through public GitHub issues.

Please send an email detailing the vulnerability along with steps to reproduce it to the project maintainer.
